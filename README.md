# Myat Kyaw Kaung — Defensive Cybersecurity Portfolio

Static GitHub Pages portfolio website for SOC, MDR, DFIR, Malware Analysis, Threat Hunting, CTF walkthroughs, defensive projects, and investigation cheatsheets.

## Structure

```text
.
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Local Preview

From the repository root:

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## GitHub Pages

This repository is intended to be served by GitHub Pages from the `main` branch root.

Expected public URL:

```text
https://myatkyawkaung.github.io/
```

## Customization Notes

- Replace "Coming Soon" cards with actual walkthrough links when ready.
- Add new project cards in the `#projects` section of `index.html`.
- Add cheatsheets in the `#cheatsheets` section.
- The theme uses a modern defensive cyber style with dark surfaces, terminal accents, subtle grid texture, and accessible responsive navigation.
